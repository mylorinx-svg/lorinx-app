# Kling brief — runners enter, run, exit (seamless loop)

**Mode:** Image to Video, using **Start frame AND End frame** if available (both = `lorinx-empty-track-start-end-frame.jpg`, an empty wet track at dusk). If Kling only accepts one image, use it as the start frame.

**Prompt (paste as is):**

```
Two sprinters in orange and red racing kits sprint into the frame from the far left edge of the screen, run past the camera at full speed along the track lanes, and sprint out of the frame on the right side, leaving the track completely empty again. The first second and the last second show only the empty track with no people. Natural running stride, arms and legs cycling, water splashing at every footfall, wet-track reflections, slight motion blur. Locked-off camera at low height, no camera movement. Deep blue dusk sky with a warm orange horizon, stadium floodlights glowing. Cinematic, realistic. No text, no logos, no brand marks.
```

**Negative prompt (if the field exists):** `text, watermark, logo, brand marks, camera shake, morphing limbs, extra limbs, people standing still, crowd`

**Settings:** 16:9, 1080p if available, 5 s (10 s if the plan allows, it gives the runners more time on screen), no audio, 1 generation.

**What to check in the result:** the first and last frames are the same empty track; the runners move left → right and fully leave the frame; no text or logos. Download without a watermark if the plan allows.

Then send the MP4; the hero already supports a looping clip, so no code change is needed.

All copy below is implemented in the draft theme and editable in the theme editor. Prices, delivery times, return terms and warranty wording were taken from the live store and its policies and were not changed. Nothing here is a testimonial; no review was written.

## 6. What was removed, and why

| Removed from the draft | Reason |
| --- | --- |
| "עד 30% הנחה במארזים", "20% הנחה", struck-through prices | Compare prices were multiples of the unit price, not prices ever charged; replaced with the real saving in shekels |
| "הנמכר ביותר" | No sales data was checked to support it |
| "4.9 · 46+ ביקורות מאומתות", named quotes, "ביקורת מאומתת" | Hardcoded, not from a review system; names repeat with different quotes |
| "מקצר את זמן ההחזרה", "מסייע להרגעת האזור", "מומלץ במיוחד לאנשים עם כאבי גב" | Treatment-style claims without substantiation |
| "סוכרתיים" and "אחרי לידה" audience cards | Target medical populations |
| "תור לפיזיותרפיה עולה כסף וזמן" | Positions the device as a substitute for treatment |

Still present because it is product data: the product title "כוס רוח חשמלית להפחתת כאבים" and the first paragraph of the Shopify description ("בלי תור לפיזיותרפיה").
